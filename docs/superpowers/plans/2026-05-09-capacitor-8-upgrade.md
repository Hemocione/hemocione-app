# Capacitor 8 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade hemocione-app from Capacitor 7 to Capacitor 8, including all official plugins, third-party plugins, Android (Gradle/AGP/SDK), and iOS (deployment target) toolchains.

**Architecture:** Follow the official Capacitor 8 migration guide (https://capacitorjs.com/docs/updating/8-0) and plugin migration guide (https://capacitorjs.com/docs/updating/plugins/8-0). Run `npx cap migrate` to automate most native changes, then audit each touched file against the spec. Keep CocoaPods on iOS (no migration to SPM). Bump third-party plugins to their Capacitor-8-compatible majors: `capacitor-plugin-safe-area@^5.0.0`, `@capacitor-community/in-app-review@^8.0.0`. The `onesignal-cordova-plugin` is unaffected by Capacitor majors (Cordova-on-Capacitor layer); bump it to latest patch only.

**Tech Stack:** Capacitor 8 · Node 22 · Nuxt 3 · Yarn · Android Gradle Plugin 8.13.0 · Gradle 8.14.3 · iOS deployment target 15.0 · Xcode 26+

**Pre-decided:**
- Branch in-place: `chore/capacitor-8` on top of current `main` (3 unpushed docs commits stay).
- Keep CocoaPods on iOS (do NOT migrate to SPM).
- Leave `--annotate` PNG at repo root untouched.
